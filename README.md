# 轻转视频

一款给普通人用的桌面视频格式转换器。它会打开自己的窗口，在你的电脑上读取视频、显示预览，并用本机的 FFmpeg 完成转换。视频不会上传到网络。

GitHub 仓库：[Fu777777/qingzhu-video-converter](https://github.com/Fu777777/qingzhu-video-converter)

## 它为什么算桌面软件

这个项目用 Electron 45 创建系统窗口，不是网页、原型图或命令行工具。窗口里的按钮和文字由本地 HTML/CSS/JavaScript 绘制；选择文件、调用 FFmpeg 都发生在本机主进程里。渲染页面不能直接访问 Node.js，只能通过隔离的 preload 通道请求主进程。

目标电脑是 Windows。界面字体优先使用微软雅黑。打包配置仍然是 `electron-builder` 的 Windows NSIS 安装包。本次复查是在 Linux 云端桌面完成的，所以 Windows 安装包没有重新生成，也没有在 Windows 上重跑。

## 功能

- 用“选择视频文件”或把视频拖进窗口来导入。
- 导入后显示文件名、大小、时长、分辨率、视频编码和帧率。读不到的项目显示“未知”，不会编造。
- 提取一张预览图。提取失败时仍显示已经读到的信息，并提示可以继续转换。
- 转换成 MP4、MOV、MKV 或 WebM，可选标准、高画质、较小文件。
- 转换时显示进度；时长未知时显示“处理中”。可以取消，取消后界面恢复，未完成的临时文件会被删掉。
- 不会覆盖已经存在的目标文件。文件名里的句点会保留，例如 `假期.海边` 不会被改成 `假期`。
- FFmpeg 用参数数组启动，不把路径拼进 shell 命令。

## 环境要求

- Windows 10 或更新版本。
- Node.js 20 或更新版本，以及 npm。日常使用也可以只安装打包后的程序；从源码运行才需要 Node.js。
- 已安装 FFmpeg 和 FFprobe，并且两个程序都在系统 PATH 里。安装后要重新打开本应用。

应用不会自动下载 FFmpeg。MP4、MOV、MKV 需要 H.264 和 AAC 编码器；WebM 需要 VP9 和 Opus。不同的 FFmpeg 安装包支持的编码器可能不同。

## 从源码运行

```powershell
npm install
npm start
```

开发时可以运行自动测试。测试会从 PATH 查找 `ffmpeg` 和 `ffprobe`，不会写死某个系统路径。

```powershell
npm test
```

```powershell

```

成功后，Windows 安装包会出现在 `dist/`。本次 Linux 环境没有重新执行打包，安装包和安装后的启动都未验证。项目也没有配置代码签名。

## 使用步骤

1. 打开应用，确认右上角显示“FFmpeg 就绪”。如果显示缺少 FFmpeg，先安装并重新打开。
2. 点击“选择视频文件”，或把一个视频拖到虚线区域。
3. 看预览和视频信息是否符合预期。
4. 选择格式、画质、文件名和保存文件夹。
5. 点击“开始转换”。需要停止时点“取消转换”。
6. 完成后可以打开结果，或到保存位置查看。

一次只处理一个视频。转换过程中不能更换视频或修改输出设置。

## 常见问题

**右上角显示缺少 FFmpeg / FFprobe**

安装 FFmpeg，把 `ffmpeg.exe` 和 `ffprobe.exe` 所在目录加入系统 PATH，然后重新打开应用。

**提示文件损坏或没有视频画面**

这个文件可能不是视频、是空文件，或者已经损坏。请另选一个视频。

**提示没有权限写入保存位置，或保存位置不存在**

另选一个真实存在、并且你有权限写入的文件夹。

**提示目标文件已存在**

原文件不会被覆盖。请修改文件名，或换一个保存位置。

**提示缺少编码器**

更换包含 H.264/AAC 或 VP9/Opus 的 FFmpeg 版本，或改用其他输出格式。

## 已知限制

- 必须单独安装 FFmpeg，应用不会自带。
- 读取视频信息时不能取消，只能取消正在进行的转换。
- 系统文件选择框的按钮文字跟随操作系统语言。本次云端系统是英文，所以选择框里的 Open / Cancel 是英文；应用自己的界面是中文。
- “打开文件”是否能播放，取决于 Windows 是否为该格式关联了播放器。本次没有验证播放器。
- Windows 安装包、安装后的启动和代码签名，本次都没有验证。
